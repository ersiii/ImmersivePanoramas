### What does it do?

**Immersive Panoramas** replaces the static vanilla main menu with a panoramic view of your actual in-game locations.

Whenever you quit a singleplayer world or disconnect from a multiplayer server, the mod instantly captures a full 360° cubemap of your surroundings, seamlessly transitioning to your last location while facing the exact same direction you were looking when you left.

### Key Highlights

- **Instant GPU Capture**: Textures are read directly on the GPU at disconnect without freezing the game or causing frame hitching.
- **Direction Alignment**: Preserves camera yaw and pitch so your view when returning to the title screen smoothly matches where you were facing.
- **Save Screen Polishing**: Matches the vanilla background blur and dimming so exiting a world feels seamless.
- **World & Server Filters**: Full control over where panoramas are taken using an in-game config screen.

### In-Game Configuration

Access the configuration screen via [Mod Menu](https://modrinth.com/mod/modmenu) on Fabric/Quilt or directly through the native **Mods** list on NeoForge:

![Immersive Panoramas Config Screen](https://cdn.modrinth.com/data/cached_images/0d346bfef60747ec245794326c8ffdf254839641.png)

| Setting | Description |
| :--- | :--- |
| **Enable Panoramas** | Toggle dynamic background captures on or off globally. |
| **List Mode** | Switch between **Allow List** (only take captures on listed worlds) and **Block List** (capture everywhere except selected worlds). |
| **World & Server List** | A live checklist showing your local worlds and multiplayer servers to toggle individually. |

### Installation & Compatibility

- **Download**: Grab the latest release on [Modrinth](https://modrinth.com/mod/immersive-panoramas) for your loader.
- **Supported Loaders**:
  - **Fabric** & **Quilt** (use the Fabric JAR)
  - **NeoForge** (use the NeoForge JAR)
- **Config GUI**: Accessible via [Mod Menu](https://modrinth.com/mod/modmenu) on Fabric/Quilt, or the built-in **Mods** config button on NeoForge.
- **100% Client-Side**: This mod runs entirely on your client. You can freely join vanilla, Fabric, Paper, Spigot, or Forge/NeoForge servers without having the mod installed on the server.
